## Fork compatibility

The #530 patch applies cleanly to `crates/brush-train/src/train.rs`. Refinement
indices come from a set, so each parent row is assigned once. Parent rotations
retain their raw quaternion values; children continue to inherit normalized
rotations. The fork's screen-size-dependent split shrink, minimum-scale
lifecycle, phase schedules, appearance training and seeded sampling remain
intact.

Optimizer assignments use the inner device and derive each zero tensor's shape
from the moment being reset. This preserves reduced second moments, including
the SH optimizer's `[N, 1, 1]` representation. Direct assignment also clears
non-finite parent moments, whereas subtracting a moment from itself can leave
NaNs. No dependency or public API changes are needed.

## Validation

The new regression invokes production refinement with ordinary and screen-capped
splits. It verifies untouched rows, raw parent and normalized child rotations,
centroids, scale, opacity, SH copying, and parent/child optimizer resets across
all three tensor ranks and reduced SH second moments.

Before applying the patch, the training suite passed 25 existing tests and
failed this regression: non-finite parent moments remained NaN instead of zero.
After applying the patch, the regression passes.
